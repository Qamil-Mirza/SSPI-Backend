Shared questions (decide once, they apply to several indicators)

1. If a country has real data, should we still fill it in?

Affects DEFRST, CARBON, WATMAN, BIODIV · DEFRST-1, CARBON-1, WATMAN-3, BIODIV-4
What is the problem

Several indicators fill in missing data for a fixed list of countries written into the old code. The lists were correct when they were written. Since then, some of those countries have started reporting real data, so the old code now produces two different scores for the same country and year.

Possible directions
  1. AKeep the fixed country lists exactly as written, and add a tie-break rule for when both scores exist.
  2. BReal data always wins. Only fill in data for a country that does not have it. Recommended Why: we already approved this rule for WATMAN, it gives the same result as the old code wherever the old code still works, and it keeps working as sources update.
  3. CStop filling in data for these countries and leave them unscored.

2. Which countries and years go into the "average" used to fill gaps?

Affects BIODIV, CARBON, DEFRST, AIRPOL · BIODIV-2, CARBON-2, DEFRST-3
What is the problem

When a country has no data, the old code gives it the average of every value in the source: every country in the world and every year, including years outside 2000–2023. No document says this is intended. Because new years keep entering the average, a country's filled-in score for 2005 can change when the source publishes 2025 data.

Possible directions
  1. AKeep the current rule: all countries, all years.
  2. BUse only SSPI countries and only the years 2000–2023. Recommended Why: it compares a country with the group it is ranked against, and past filled-in scores stop moving when the source adds new years.
  3. CUse a separate average for each year, so filled-in values follow the global trend over time.

3. What is the official scoring window?

Affects BIODIV, GINIPT, and others · BIODIV-5, GINIPT-3
What is the problem

Filled-in data stops at 2000–2023, but real data is scored for every year the source has (sometimes 1960s to 2025). So for 2024 and 2025, countries with complete data have scores and countries that need filling in do not. The old website hid this by only showing 2000–2023.

Possible directions
  1. AKeep storing everything and let each reader pick the years they need.
  2. BMake 2000–2023 the official window: fill in and publish only inside it, and keep extra real years stored but unpublished. Recommended Why: every country is covered for the same years, so comparisons are fair, and no real data is thrown away.
  3. CMove the window forward to the latest year (2025) for every indicator.

Blocking: these indicators cannot run until decided

DEFRST · Deforestation

DEFRST-1, DEFRST-2, DEFRST-3
Blocked: the indicator stops with an error on current FAO data.
What this indicator measures

How much a country's forest area has changed compared with its average forest area in the 1990s.

What is the problem
  • The old code always gives Belgium, the United Arab Emirates and Luxembourg a filled-in score. The Emirates now have real forest data, so there are two different scores for the same years.
  • The forest baseline only runs to 2022, so every 2023 score is a copy of 2022. The carbon indicator, built the same way, runs to 2025.
  • The written formula is missing the "× 100" the code uses. This is a text fix only.
Possible directions
  1. AKeep the fixed country list and choose which of the two Emirates scores to keep.
  2. BReal data wins: the Emirates are scored from their own data, and Belgium and Luxembourg keep the filled-in score. Recommended Why: it unblocks the indicator today and uses the same rule as Shared question 1.
  3. CDo B, and also extend the forest baseline to every year so 2023 onward gets real scores, matching CARBON.

CARBON · Carbon Storage in Forests

CARBON-1, CARBON-2
Blocked: the indicator stops with an error on current FAO data.
What this indicator measures

How much carbon a country's forests store compared with its average in the 1990s.

What is the problem
  • The old code always gives Kuwait, Belgium and Luxembourg a filled-in score. Kuwait now has real data, so it gets two different scores for every year 2000–2023.
  • The filled-in value comes from a world average. In the old system that average probably included countries that no longer exist, such as the USSR, which pushed the filled-in score to zero.
Possible directions
  1. AKeep the fixed country list and choose which of Kuwait's two scores to keep.
  2. BReal data wins: Kuwait is scored from its own data, and Belgium and Luxembourg keep the filled-in score. Recommended Why: it unblocks the indicator today and uses the same rule as DEFRST and WATMAN.
  3. CDo B, and also change how the filled-in value is built so DEFRST and CARBON fill gaps the same way.

Other indicators

BIODIV · Biodiversity Protection

BIODIV-1, BIODIV-3
What this indicator measures

The share of important marine, land and freshwater biodiversity sites that are protected.

What is the problem

Landlocked countries have no marine sites. The code gives them the world average for marine and then averages all three parts. The old documentation and the 2018 published scores averaged only the two parts they have. The difference is large: Czechia scores 0.75 now and would score 0.94 the other way.

Possible directions
  1. AKeep filling in marine with the world average and averaging all three parts.
  2. BAverage only the parts a country actually has data for. Recommended Why: a country should not be scored on a habitat it does not have, and this matches the 2018 published scores.
  3. CDrop marine only for landlocked countries, and keep filling in freshwater for Kuwait and Singapore.

Also: filled-in scores use a slightly different formula that is not capped at 0–1. It changes nothing today. Recommend using the same capped formula everywhere.

REDLST · Red List Index

REDLST-1
What this indicator measures

How close a country's species are to extinction. 1 means no species are threatened; 0 means all are extinct.

What is the problem

The code and all documents score the index on a 0 to 1 scale. The 2018 published scores used a 0.5 to 1 scale, which doubles the gaps between countries. Nothing explains why.

Possible directions
  1. AKeep the 0 to 1 scale. Recommended Why: the code and every document agree; only the 2018 file differs, and it has no explanation.
  2. BSwitch to the 0.5 to 1 scale, which spreads countries out more because real values are rarely below 0.4.
  3. CAsk the original authors why 2018 differed before deciding.

CHMPOL · Chemical Pollution

CHMPOL-1, CHMPOL-2
What this indicator measures

How well a country meets its obligations under five international treaties on hazardous chemicals and waste.

What is the problem

The slot for the Rotterdam Convention is filled with Stockholm Convention data. Stockholm is counted twice and Rotterdam is never used, even though the source publishes it. Austria scores 0.65 now and would score 0.78 with the real Rotterdam data.

Possible directions
  1. AKeep it as is.
  2. BUse the real Rotterdam data. Recommended Why: this is clearly a copy-paste mistake; the indicator is meant to cover five different treaties and the data exists.
  3. CDrop Rotterdam and average the other four treaties.

Also: the written formula does not match the code. It changes no scores. Recommend correcting the text to match the code.

WATMAN · Water Management

WATMAN-1, WATMAN-2, WATMAN-3
What this indicator measures

How much a country has improved the economic value it gets from each unit of water, and how much pressure it puts on its water supply.

What is the problem
  • The old files disagree on the lowest score threshold (−20% or −25%). The description says the baseline is 2010–2015, but the code uses 2000–2005.
  • Which countries get filled-in data is a fixed list of 12 countries plus Singapore, written into the code. The method used for them is not documented anywhere.
Possible directions
  1. AKeep everything (−20%, 2000–2005 baseline, fixed lists) and fix the description.
  2. BKeep the formula, but replace the fixed lists with a rule: "fill in data for SSPI countries that have no 2000–2005 baseline." Recommended Why: it gives the same countries today and stays correct when the data changes.
  3. CRedesign the measure as change over a rolling 5 or 10 years, as the team's status note suggests.

NITROG · Nitrogen Management

NITROG-1
What this indicator measures

How sustainably a country uses nitrogen fertilizer, taken from Yale's Environmental Performance Index (EPI).

What is the problem

The 2024 EPI file the old code used is no longer online. The new 2026 edition recalculates every past year with different scaling. Scores shift for reasons that have nothing to do with what countries did.

Possible directions
  1. AAlways use the latest EPI edition, recalculate every year from it, and never mix editions. Recommended Why: it is the only source that keeps getting updated, and each edition is consistent with itself across years.
  2. BFreeze on the 2024 edition (we have an archived copy). It is stable, but gets no new years.
  3. CTake the raw nitrogen data and apply our own SSPI thresholds, so EPI rescaling no longer affects us. Most stable, most work.

GINIPT · Income Inequality (Gini After Taxes)

GINIPT-1, GINIPT-2, GINIPT-3
What this indicator measures

How evenly income is shared in a country, using the Gini coefficient.

What is the problem
  • The name says "after taxes," but the World Bank data we use is not after taxes. It also mixes income surveys and spending surveys, which are not directly comparable.
  • Kuwait, New Zealand, Saudi Arabia and Singapore have no World Bank data. Today they get a predicted score; in 2018 they got values from another source (likely the CIA World Factbook).
  • Filled-in data reaches outside 2000–2023 and outside SSPI countries, unlike other indicators.
Possible directions
  1. AKeep the World Bank data, rename the indicator to say what it measures, keep the prediction for the four countries, and limit filling-in to 2000–2023 and SSPI countries. Recommended Why: keeps the widest coverage, makes the label honest, and lines it up with the other indicators.
  2. BSwitch to a true after-tax inequality source, accepting different country and year coverage.
  3. CKeep the World Bank data, but use a named second source for the four missing countries instead of a prediction.

EMPLOY · Participation in Paid Employment

EMPLOY-1, EMPLOY-2
What this indicator measures

The share of working-age people who have a paid job.

What is the problem

The description says ages 25–54, and in 2018 the indicator measured people working or looking for work. The code now measures only people with a job, ages 15–64. That number is much lower, and the score thresholds were set for the old measure. India drops from 0.62 (2018) to 0.

Possible directions
  1. AKeep the ages 15–64 job measure, fix the description, and lower the score thresholds.
  2. BUse the share of people aged 25–54 who have a job. Recommended Why: it matches the description and the name "paid employment," and the 25–54 age range is not distorted by students or early retirement.
  3. CGo back to the 2018 measure: people aged 25–54 working or looking for work.

Also: filled-in scores are labelled "Tax Rate" by mistake. Recommend labelling all of them "Percentage." No score changes.

COLBAR · Collective Bargaining Coverage

COLBAR-1, COLBAR-2
What this indicator measures

The share of workers whose pay and conditions are covered by a collective agreement.

What is the problem

Ten SSPI countries have no data: Algeria, Ecuador, India, Iran, Iraq, Kuwait, Nigeria, Pakistan, Saudi Arabia and the UAE. The methodology planned a value for each of them, but nobody ever wrote them in, so they have no score at all.

Possible directions
  1. ALeave the ten countries unscored.
  2. BResearch a value and a named source for each of the ten countries, as originally planned. Recommended Why: it was always the plan, and for several countries (Kuwait, Saudi Arabia, the UAE) the 2018 data already had values.
  3. CGive the ten countries the average of the other SSPI countries.

Also: the data carries three different unit labels ("Proportion", "%", "Tax Rate"). Recommend using "%" everywhere. No score changes.

NRGINT · Energy Intensity

NRGINT-1
What this indicator measures

How much energy a country uses to produce each dollar of GDP. Lower is better.

What is the problem

The source switched from 2017 dollars to 2021 dollars. Our score thresholds were set for 2017 dollars and were not changed. As a result, most countries look about 14% more efficient without anything real changing.

Possible directions
  1. AKeep the thresholds and update the description to say 2021 dollars. Recommended Why: it is the simplest fix, and all years are recalculated from the same series, so comparisons between countries and years stay fair.
  2. BAdjust the thresholds to 2021 dollars so scores keep the same meaning as before.
  3. CConvert the data back to 2017 dollars ourselves.

AIRPOL · Air Pollution

AIRPOL-1, AIRPOL-2
What this indicator measures

The average yearly level of fine particle air pollution (PM2.5) that people breathe.

What is the problem
  • It is called "Urban Air Pollution" and described as cities only, but the code uses the figure for the whole country.
  • The data starts in 2010, so every score for 2000–2009 is a copy of the 2010 score.
Possible directions
  1. AKeep everything as it is.
  2. BKeep the whole-country figure, rename the indicator "Air Pollution," and look for a source that covers 2000–2009. Recommended Why: the team's own status file already calls it "Air Pollution," it covers everyone, and a longer source fixes the copied years.
  3. CSwitch to the cities figure to match the current name. Pollution is higher in cities, so scores would fall.

ALTNRG · Alternative Energy

ALTNRG-1, ALTNRG-2
What this indicator measures

The share of a country's energy that comes from low-carbon sources (nuclear, hydro, solar, wind and others), with biofuels counted at half.

What is the problem
  • The 2018 definition used a different measure (energy consumed, not energy supplied). The descriptions mix both.
  • The data labelled "Geothermal" is actually solar, wind and other renewables.
  • Most countries have no nuclear power. The code treats that as missing data, so most scores are flagged "filled in." It also carries closed plants forward: Lithuania's nuclear plant closed in 2009 but still counts through 2023.
Possible directions
  1. AKeep everything and fix the names and descriptions.
  2. BKeep the current formula, fix the names, and treat an unreported fuel as zero in the main calculation. Recommended Why: no nuclear power really means zero, so these scores stop being wrongly flagged and closed plants stop being counted.
  3. CGo back to the 2018 definition (share of energy consumed).
